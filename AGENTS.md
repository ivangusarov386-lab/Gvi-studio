# Инструкции для работы с проектом

Пользователь берёт готовый код Google Apps Script из папки `apps-script/` в этой ветке. После любого изменения интерфейса, стилей, логотипа или связанных клиентских модулей выполните `npm run build:google` и включите актуальный `apps-script/Index.html` в тот же коммит. Серверный код Apps Script и манифест поддерживайте актуальными непосредственно в `apps-script/`. Не помещайте секреты, данные пользователей или выгрузки таблиц в репозиторий. Проверка GitHub Actions проверяет соответствие собранного HTML исходникам.
