# GVI Studio — Swiss minimalism

Молочный фон `#faf7f2`, чёрный `#151515`, оранжевый `#f57900`. Arial/Helvetica, строгая модульная сетка, прямые углы, тонкие линии. Четыре проекта, рабочая область и блок действия сохранены из исходного архива.

Оригинальный `assets/gvi-studio-logo.jpeg` не изменялся. Изображение целиком помещается в квадрат с `object-fit: contain`, без отрицательных смещений и обрезки.

Панель теперь запускается через `npm start`: ES-модули, локальное сохранение и серверное демо-API. Адаптивные формы, касания от 44 CSS px, видимый фокус, семантические кнопки/поля, `dialog`, Escape, ссылка пропуска навигации. Мобильные проверки выполнены в Chromium с эмуляцией, не на реальном iPhone.

Визуальные решения основаны на исходном макете и общих правилах доступности навыка UI/UX Pro Max; поиск по его локальной базе не запускался (локального пакета поиска в среде нет). Полный тёмный режим не предусмотрен: приложение объявляет светлую цветовую схему.
