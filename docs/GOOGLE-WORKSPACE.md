# Задачи GVI Studio в Google Sheets

Панель остаётся на GitHub Pages. Отдельная таблица Google хранит задачи; Apps Script принимает запросы сайта, как в примере ГТО. Таблицы ГТО и их код не используются. Материалы, файлы, ошибки и версии пока остаются в браузере.

## Подключение

1. Сначала в GVI Studio откройте «Настройки» и экспортируйте резервную копию существующих задач.
2. Создайте **новую пустую** Google-таблицу для GVI Studio. Откройте в ней «Расширения → Apps Script».
3. В файле `Code.gs` замените содержимое кодом из [apps-script/Code.gs](../apps-script/Code.gs). В настройках проекта включите отображение манифеста и вставьте [appsscript.json](../apps-script/appsscript.json). В сервисах должен быть подключён Google Sheets API v4. Файл Index.html для этого варианта не нужен.
4. Сохраните проект. Выполните `setupWorkspace` и подтвердите разрешения Google. Скрипт использует открытую пустую таблицу; если он запущен отдельно от таблицы, создаст новую. Повторный запуск не очищает задачи.
5. Выполните `setupTaskPassword`. В появившемся окне таблицы задайте личный пароль от 12 символов. Пароль хранится в настройках скрипта; не вставляйте его в код, GitHub или чат. Для смены повторите функцию — старые сеансы перестанут работать.
6. Создайте развёртывание «Веб-приложение»: выполнять от вашего имени; доступ «Все» (включая анонимных). Это необходимо для вызова с GitHub Pages. Сама таблица остаётся закрытой; сервер проверяет пароль для чтения и записи. URL развёртывания не является паролем. Для будущих изменений создавайте новую версию существующего развёртывания.
7. На существующем сайте GVI Studio откройте «Настройки → Таблица задач», вставьте URL вида `https://script.google.com/macros/s/.../exec` и нажмите «Подключить». После перезагрузки введите пароль. Повторите настройку URL и вход на другом устройстве.
8. Для переноса своих прежних задач импортируйте ранее экспортированную копию в настройках. Новые задачи добавляются без замены существующих; стартовые примеры и материалы не переносятся. Проверьте создание и изменение тестовой задачи с двух устройств.

## Важно о защите и проверке

Пароль передаётся только по HTTPS, не хранится в клиентском коде и не добавляется в Git. Временный подписанный сеанс хранится только в памяти вкладки до её перезагрузки или закрытия; смена пароля отзывает сеансы. После 20 неверных попыток вход временно блокируется на минуту. Скрипт отклоняет чтение и запись без действующего сеанса. Ссылку на веб-приложение можно знать без доступа к задачам, но не публикуйте пароль.

Google Apps Script развёртывается публично на уровне URL, поэтому выбирайте сильный уникальный пароль. Ограничение попыток общее и основано на временном кеше Apps Script, это базовая защита личного прототипа. Не используйте панель для персональных данных участников ГТО.

Хеш снимка и ScriptLock защищают от незаметной перезаписи между устройствами панели. При конфликте обновите данные и повторите изменение. Ручное изменение самой таблицы одновременно с записью из панели не блокируется. Для надёжности редактируйте задачи через панель и делайте резервные копии.

Реальное развёртывание, междоменные запросы и разрешения Google ещё не проверены: в среде Codex нет доступа к вашему аккаунту Google. Код проверяется локально с синтетическими данными. GitHub Pages не запускает Apps Script автоматически: после каждого изменения серверного кода требуется новая версия развёртывания.
