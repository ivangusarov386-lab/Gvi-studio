## Что проверено

Расчёты: разные ID регистрации/участника/попытки; дубли и конфликтные ID; выбор последней сдачи внутри периода; неоднозначность одинакового времени; пустые/неизвестные статусы; противоречие «не сдал + уровень»; невозможные даты; переход суток по Москве; включительные границы; независимость даты мероприятия; пустые и категорийные выборки.

Адаптер: два отдельных источника, точные заголовки, отклонение пропавших/дублирующихся столбцов, явное сопоставление статусов; пустые значения остаются неизвестными. Через подменённый Google HTTP-клиент проверены только GET-запросы к values API и отсутствие обращения к A2. **Это не проверка доступа к Google Sheets.**

Сервер: агрегаты без ID участников; запрет выдачи `.env` и серверных файлов; отсутствие write-методов; авторизация обязательна в live; запрет работы без подтверждённых правил; безопасное сообщение об ошибке; кеш при сбое обозначен устаревшим; демонстрационные записи не подставляются; повторный сбой источника не вызывает частые запросы.

Браузер: переходы по четырём проектам, задачи — создание/изменение/статус/срок/фильтр и перезагрузка; материал с файлом сохраняется после перезагрузки; две версии сопоставляются; ошибки сохраняются; ручные проценты ролика требуют периода/определения; экспорт и импорт резервной копии; HTML-подобный текст остаётся текстом; загрузка, пустая выборка, потеря сети и отметка устаревших данных. Проверены Tab и Escape, видимые формы и подписи.

Адаптивность: ширины 375, 390, 844 и 1440 CSS px; горизонтального переполнения нет. Логотип имеет исходные пропорции, `object-fit: contain`, целиком внутри экрана. Касания основных кнопок/полей имеют минимум 44 CSS px. Снимки ниже просмотрены; полный аудит VoiceOver и масштабирования системного текста не проводился.

Вместо скачиваемого Chromium использован уже установленный системный Chromium. В конфиге предусмотрен необязательный WebKit через `GVI_TEST_WEBKIT=1` после установки.
- Настоящий iPhone: не проверен. Мобильная эмуляция Chromium не подтверждает поведение Safari, клавиатуры или файлового хранилища на устройстве.
- Реальная или внешняя синтетическая Google-таблица: не подключена, ссылок/схемы нет. Переменная `GOOGLE_APPLICATION_CREDENTIALS` в среде присутствует; её значения не выводились, пригодность и права на Sheets не проверены. Создавать дублирующий ключ до этой проверки не нужно.

- Live HTTPS-размещение, работа за reverse proxy, доступ с двух настоящих устройств и серверная синхронизация не проверялись и не заявляются готовыми.

## Исправление GitHub Pages, 14 ноября 2026

Скриншот владельца показал поломку опубликованной страницы. Причины: абсолютные пути `/styles.css`, `/app.js`, `/assets/...` не учитывали `/Gvi-studio/`, а статический хостинг не исполняет серверный `/api/gto`.

Исправлены относительные пути и введён явный статический деморежим без API. Добавлена проверка выдаваемого Node runtime-модуля и отдельные Playwright-сценарии статического сервера в подпапке: CSS, загрузка исходного логотипа, четыре проекта, отсутствие 404 и запросов к API, сохранение задачи после перезагрузки и фильтры синтетических данных. Проверяются desktop и мобильная эмуляция Chromium.

Новые снимки: [Pages — компьютер](../screenshots/pages-desktop.png), [Pages — мобильный экран](../screenshots/pages-iphone-chromium.png).

Прямой запрос к опубликованному `ivangusarov386-lab.github.io` из облачной среды блокируется сетевой политикой (403 на CONNECT). Поэтому локальная проверка такой же подпапки отделена от проверки фактического развёртывания Pages. Safari на реальном iPhone по-прежнему не проверен агентом.
